# Служебные инструменты VK Unified

Основное приложение использует зависимости из `requirements.txt`.

Два исторических инструмента, `bootstrap_vm_key.py` и `migrate_vk_vm.py`,
дополнительно требуют `paramiko`. Они предназначены для явного одноразового
обслуживания Windows VM и не запускаются worker или CI. При необходимости
установите библиотеку в отдельное окружение командой `python -m pip install paramiko`.

Bootstrap запрашивает пароль интерактивно и меняет настройку SSH-ключа.
Миграция может переносить рабочее состояние и профили. Не используйте эти
операции для обычной диагностики, повторного подключения аккаунта или
освобождения занятого браузера.

Обычные проверки выполняются без остановки worker. Для установки новой версии
нужно отдельно дождаться завершения пачки, сохранить backup, проверить
неизменность истории и восстановить исходные определения задач.
