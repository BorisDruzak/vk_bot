# Аналитика внутри основной VM-панели

По прямому запросу добавлена вкладка «Аналитика» на
http://192.168.100.46:8787/#analytics. Работает с существующей сессией панели,
без Codex, локального preview-сервера, второго входа и отдельного порта.
После перезапуска панели требуется обычный повторный вход. Старую открытую
страницу нужно обновить, поскольку переход только на #analytics её не перезагружает.

## Данные и правила

- Выбор последнего или исторического завершённого замера, все64сообщества.
- Известные суммыL/K/R/V и покрытиеK/N у каждого паблика; формула по отношению
  сумм основных записей, не среднее процентов, не охват. ПредварительныйER/П3.3
  только по строкам с четырьмя известными счётчиками; полный результатUNKNOWN
  при неполноте/открытом периоде. Исторические NULL не становятся нулями.
- Выбор календарных недель либо полных7дней от начала периода, репостов,
  поиск паблика, ссылки на отдельные записи с датами/временем замера/статусом.
- Недельный минимум считается по доступным основным записям. Даже частичный
  архив может доказать>=3; закрытая неделя с<3 при неполном покрытииUNKNOWN,
  а не failed. Незавершённая на момент выбранного замера неделя — open.
  Позднейшая дата просмотра не превращает старый незакрытый замер в нарушение.
- Страницы-визитки и исключения — из frozen состава. G/(C-Cv) выводится для
  закрытой недели только при определённом результате. Правила недель/репостов
  и официальный состав по-прежнему требуют ЦУР.
- Обновление перечитывает SQLite; не вызывает VK/API/браузер/actor operations.
  Новый сбор независимо выполняется существующей VM-задачей08:00/20:00.

## Реализация

Новый vk_analytics_web.read_analytics открывает только vk_analytics.sqlite3
через URI mode=ro, с краткой согласованной read-транзакцией и явным closing.
Не создаёт БД/каталоги, не вызывает миграции и не читает историю actor.
GET /api/analytics принимает только run/weeks/reposts с строгой валидацией,
session+CSRF+origin/host guards; ошибки не раскрывают пути/сырой exception.
Нет нового RPC-действия или мутационного endpoint. Код подключён только
к local-backend VM. Старый remote режим явно не имеет локального источника.

web/analytics.js — отдельный renderer, общий CSS/визуальный стиль. Всё
пользовательское содержимое через textContent, без HTML-вставок. Сохраняются
фильтры при смене вкладок; поздние ответы отменяются/игнорируются. При ошибке
старые данные остаются с явной подписью. Logout очищает данные/CSRF/inflight.
Пустая БД и недоступный backend имеют отдельные состояния.
