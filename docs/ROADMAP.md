## Правила приемки

После каждого изменения: тест на временной SQLite, unit/regression, отсутствие живых запросов из CI, проверка `.gitignore`, `git diff --check`, отчёт об известных ограничениях. Применение изменений к рабочему аккаунту — только с явным запуском оператором. При VK rate limit не предпринимать автоматические повторные попытки до ручной проверки.
