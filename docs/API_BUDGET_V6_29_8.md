# Увеличение локального бюджета API — v6.29.8

22октября2026 после объяснения стоимости40 обновлений пользователь прямо поручил увеличить лимит. Новый `scan.daily_requests`: **5000 запросов за скользящие24часа** вместо2000. Это потолок локального скрипта, не утверждение об официальной квоте VK.

Минимум40×56=2240 читающих запросов перед пачками оставляет2760 из5000 на дополнительные страницы и фоновый каталог. Значение согласовано в schedulerнастройках и проверке каталога с уже существующим пределом VKReadClient5000. Scheduler явно передаёт настройку обоим читающим путям. Legacy-вызов catalog.step без явного daily_limit по-прежнему имеет прежнее значение2000; это не рабочий путь scheduler.

Расход продолжает считаться по прежнему `api_read_attempts`; таблица, времена и старые попытки не удаляются/не обнуляются. Оба читающих пути разделяют один бюджет. При его исчерпании сохраняется budget без использования старых счётчиков. HTTP429/CAPTCHA/auth/прочие защиты не отменяются. Количество доступных постов, ошибки и пропущенные интервалы всё ещё могут уменьшать дневной результат; полные160 не объявляются принятыми.

Без изменений: APIпауза≥5сек, после попытки действия≥20сек, начала разных пачек≥10мин, максимум4 попытки, окно09–19YEKT, по50лайков/10личных/20community на аккаунт (10+10), общий максимум160. Не догонять пропуски, не повторять отправки. Job47/75 остаются двумя явно разрешёнными изолированными uncertain с расходом квоты.

Регрессия до изменения кода воспроизвела отказ scheduler и каталога при5000. После исправления62 профильных теста PASS. Проверены: принятие5000 с полностью неизменной policy, отказ5001/bool/0;4999 прежних запросов + один новый исчерпывают5000, второй сетевой запрос не происходит, курсор другой группы сохраняется; реальных actionattempts0.

Установка требует штатного перезапуска worker для загрузки настройки; это операция обновления по запросу пользователя, не остановка ради проверки. Резервная копия/сверка таблиц/результат установленной проверки фиксируются после завершения. GitHubпубликация отдельно не разрешена.
