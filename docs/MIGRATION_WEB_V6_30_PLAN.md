# VK Unified v6.30 — план и журнал исполнения

Задача пользователя: основная машина `vk-bot@192.168.100.46`, SSH по ключу,
Chrome и перенос полных профилей; CLI для дополнительных аккаунтов, включения
в очередь и индивидуальных квот; HTTP панель на Windows по IP и порту.
Канонический GitHub: https://github.com/BorisDruzak/vk_bot (`main`).

## Решения и ограничения

- Один исполнитель и единственная история на Windows VM. По уточнению пользователя
  панель тоже на VM `192.168.100.46:8787`, local backend; SSH RPC дополнителен.
  Живые SQLite обратно не синхронизируются.
- Произвольные положительные номера аккаунтов, независимые профили и SQLite.
  Новый аккаунт выключен до подтверждения VK ID и явного включения.
- Квоты на аккаунт в пределах 50/10/20. Окно 09–19 YEKT, sleep20,
  API >=5 секунд, бюджет 5000/24ч, пачки <=4 и >=10 минут сохраняются.
- Сохранённый план текущего дня не перестраивается. Новые квоты и аккаунты
  применяются к первому не спланированному дню, отключение действует сразу.
- Исходы uncertain, изоляции и расход сохраняются. Панель не содержит
  retry/reset/unpause и не выдаёт ложного подтверждения результата.
- Статистика последних 100 API постов: nullable likes/comments/reposts/views,
  время наблюдения и источник; неизвестное отображается как отсутствие данных.
- Доступ HTTP с аутентификацией, пароль хранится как salted scrypt hash;
  серверные мутации защищены проверкой Origin и CSRF. Авторизация VK только
  в отдельном профиле на VM; перенос между машинами/пользователями проверяется фактически.
