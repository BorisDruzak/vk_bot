## Полный исторический набор

При контроле до добавления двух тестов паузы с `PYTHONUTF8=1` общий `unittest discover` не прошёл: **231 выполненный тест, 24 ошибки**. Из них 23 совпадают по именам с отдельным контрольным запуском исходного v6.26 в той же среде (**218 тестов, 23 ошибки**). Дополнительная ошибка — setup `test_community_ui.CommunityBrowserTests`, вызванный оставшимся asyncio loop после старой браузерной фикстуры. Все 27 новых UI-тестов проходят в отдельном чистом процессе.

Первопричины исторического набора: жёсткий Linux-путь `/usr/bin/chromium`, каскад Playwright Sync API/asyncio и незакрытые SQLite при Windows cleanup. Старый cp1251-сбой не воспроизводится с `PYTHONUTF8=1`, поэтому числовое сравнение с прежним отчётом без этой переменной отличается. Исторические имена и прежние результаты — [VALIDATION_V6_26.md](VALIDATION_V6_26.md). Полный набор не заявляется зелёным; его стабилизация остаётся отдельной задачей.
