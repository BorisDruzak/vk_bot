# Исправление семи дефектов ревью

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** исправить R1–R7 из CODE_REVIEW_2026_10_26.md с проверяемыми регрессиями.

**Architecture:** минимальные изменения в существующих границах API, analytics, registry и scheduler. Общий API-reader сохраняет защиту; аналитика опирается на сохранённое время чтения; реестр публикует только подготовленные базы; UI различает отсутствие сигнала и неопределённую отправку.

**Tech Stack:** текущий Python/SQLite/unittest, Playwright и JavaScript/Node; новые зависимости не нужны.

**Spec:** `docs/CODE_REVIEW_2026_10_26.md`, R1–R7, и действующий AGENTS.md.

## Global Constraints

- 09–19 YEKT, ≥540 секунд между фактическими пачками, ≤4 попыток в пачке, sleep≥20 секунд после попытки.
- Квоты 50/10/20, API≥5 секунд и 5000/24ч; один разрешённый повтор и остановка после трёх логических неуспехов сохраняются.
- CAPTCHA/429/identity/source/date/destination/cleanup/неразрешённый uncertain остаются защитными остановками.
- Старые планы, actor history, bindings, paused, interrupted и frozen reports не мигрировать и не переоткрывать.
- Рабочие базы и профили не использовать для тестирования; установка на VM и unpause не входят в локальную правку.
- Локального Git нет: использовать source-only baseline, SHA256 и diff; не создавать фиктивную Git-историю.

## Принятые решения

Пользователь разрешил составить план и выполнить все исправления в одном запросе. Реализация продолжается без отдельного согласования плана. Из альтернатив выбран ремонт существующих компонентов; общий рефакторинг очереди или перенос в новую БД увеличил бы риск без необходимости.

Работа выполняется в отдельной копии только кода, с последующим переносом проверенных файлов в исходную папку при совпадении её исходных хешей. Зависимости установлены; Context7 недоступен по квоте, внешние контракты сверяются с официальными CPython/VK источниками. Итоговое ревью выполняет отдельный агент.

## Review Focus

1. CAPTCHA от любого reader, включая каталог и аналитику, блокирует последующее чтение; код7 остаётся локальной ошибкой группы.
2. Замер, начавшийся до конца периода и завершившийся после, не становится полным из-за позднего finish; пустая стена тоже требует сохранённого времени чтения.
3. Ошибка инициализации нового actor не публикует запись; старый actor и его попытки сохраняются.
4. Подкласс OSError с cleanup или защитой в цепочке не получает новый допуск к повтору.
5. Сигнал жизни не коммитит незавершённую транзакцию intent и не обновляется выдуманным таймером зависшего действия.
