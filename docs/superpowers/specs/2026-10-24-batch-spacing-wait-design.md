# Ожидание интервала пачки

Цель: не терять уже claimed пачку из-за небольшого недостающего интервала,
сохранив явные пользовательские ограничения540сек/4/sleep20/09–19 и no-catchup.
Основание:24октября slots1/6/11 закончились batch_spacing_wait без попыток;
для6/11 не хватало41/31сек. Сохранённый план и завершённые пачки не менять.

## Подходы

- Уменьшить540сек либо восстановить завершённые пачки: исключено прямыми
  ограничениями пользователя.
- Перегенерировать план: исключено неизменностью сохранённого дня.
- Ограниченно ждать внутри текущей claimed пачки: выбран как локальное
  исправление до intent, без повторного клика и без catch-up.

Реализация: после успешного fresh refresh, до pick/create_job, разрешить ожидание
только если earliest actual start укладывается в исходные120сек допуска запуска
этого slot, следующий slot и конец окна минус30сек. Проверять stop/paused/
active_uncertain/day/window/safety locks при каждом шаге <=5сек. Heartbeat
batch_spacing_wait остаётся свежим; лимит суммарных sleep<=120сек. После ожидания
оставить before_attempt/final_click guards неизменными. Невмещающееся ожидание
заканчивается прежним batch_spacing_wait без попытки. Первый утренний slot1
по этим границам остаётся пропуском; это не обещание полного240дня.

Панель: finished batch_spacing_wait показывать отдельно как «Пропущено:
интервал9мин»; отсутствие записи после истечения grace — явный пропуск,
будущее — запланировано, незавершённое — в работе. Неизвестный итог требует
проверки. Никаких кнопок reset/retry/unpause не добавлять.

Проверки: воспроизведение коротких41/31сек и неумещающегося утреннего ожидания,
stop/paused/uncertain/window/день/lock во время ожидания; отсутствие преждевременных
intents и сохранность плана/квот; rendered UI fixture для старого пропуска,
будущего, текущего ожидания и неизвестного результата. Изолированная source-only
регрессия, проверка установленного кода и аудит состояния VM.

Разрешение: текущий запрос об исправлении и прежнее явное поручение безопасного
авторемонта. Реальные отдельные тестовые реакции и публикация GitHub не разрешены.
