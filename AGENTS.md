## Данные и проверка изменений

- Профили Chromium, SQLite, реакции, попытки, блокировки и отчёты аккаунтов изолированы. Из общей базы в №2 переносится только публичный API-каталог; не переносить историю действий №1.
- Сохранять остановку при HTTP 429, CAPTCHA, несовпадении VK ID и неопределённом результате. Не снимать блокировки и не повторять сомнительные клики автоматически.
- Проверять код офлайн на временных базах; реальные действия выполнять по явно заданной пользователем команде и объёму.
- Не публиковать Chromium-профили, cookies, токены, `.env`, SQLite, локальные VK ID, реальные CSV, авторизованный DOM и приватные скриншоты.
