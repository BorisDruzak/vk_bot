## Репост в сообщество для обоих аккаунтов (v6.27)

Явное назначение задаётся положительным ID через `--repost-community`. Без этого флага сохраняется репост на личную стену.

```powershell
python vk_unified.py --account 1 --run-actions --reposts 1 --repost-community 242481697 --max-posts 1 --dry-run
python vk_unified.py --account 2 --run-actions --reposts 1 --repost-community 242479058 --max-posts 1 --dry-run
```

`--dry-run` проверяет выбор сообщества без финального клика и без лайков. Для реального запуска вместо него требуется `--confirm`. История и CSV разделяются по аккаунту и целевому сообществу. Подробности, локальные отчёты и ограничения подтверждения — [COMMUNITY_REPOST_CLI.md](docs/COMMUNITY_REPOST_CLI.md).

### Отдельный запуск второго аккаунта (v6.26)

Сначала обнови общий каталог через VK API (команда выполняется **под аккаунтом №1**, сервисный ключ VK только локально):

```cmd
py vk_unified.py --account 1 --discover
```

Затем просматривай локальную очередь второго профиля и его отдельную базу:

```cmd
py vk_unified.py --account 2 --check-account
py vk_unified.py --account 2 --preview --max-posts 15
py vk_unified.py --account 2 --test-status
```

Ограниченный ручной тест на двух публикациях с раздельным бюджетом действий:

```cmd
py vk_unified.py --account 2 --run-actions --likes 2 --reposts 2 --max-posts 2 --confirm
py vk_unified.py --account 2 --action-status
```

Для запуска с отдельными максимумами 5 лайков и 2 репоста, с проверкой до 10 постов:

```powershell
python vk_unified.py --account 2 --run-actions --likes 5 --reposts 2 --max-posts 10 --confirm
```

Эта команда проверена через CLI в офлайн-регрессионном тесте: 5/2 попытки и подтверждённые тестовые результаты записываются только в SQLite №2; прежние реакции №2 повторно не выполняются, база №1 не меняется. Это не проверка реальных лайков и репостов в VK.

После проверки результатов в VK и отсутствия ограничений можно задавать другой конечный объём **самостоятельным запуском**, например `--likes 30 --reposts 30 --max-posts 60 --confirm`. Это максимумы **попыток за один запуск**, а не гарантия новых 30/30. Нет автоповтора, фонового задания или одновременной работы двух аккаунтов.

**Реальный тест №2 успешно пройден 2026-10-21:**

```powershell

```

Запуск №1: `complete`, 30/30 попыток лайка и 30/30 попыток репоста; VK подтвердил 30 новых лайков и 30 новых репостов на 35 проверенных публикациях. Время: 19:36:09–20:07:53 Asia/Yekaterinburg (14:36:09–15:07:53 UTC), длительность 31:44. `--account 2 --action-status`, журнал SQLite и CSV на 35 строк подтвердили итог; в CSV отмечено ровно 30 новых действий каждого типа. Ранее существовавшие реакции пропускались. История попыток аккаунта №1 осталась прежней (71 запись до и после теста); предупреждений VK на момент завершения не было. Это результат конкретного запуска, не гарантия последующих 30/30.

Отчёт №2: `vk_actions_results_account_2.csv`. Отчёт №1: `vk_actions_results.csv`. Нельзя менять cookie-файлы, переносить SQLite между аккаунтами, снимать CAPTCHA/HTTP 429 или пытаться обойти платформенные ограничения.
